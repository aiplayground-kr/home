# AI Playground · Microsoft Korea

AI놀이터 시즌 행사와 작은 놀이터의 포스터, 현장 기록, LinkedIn 후기를 모아보는 커뮤니티 아카이브입니다.

## Website

- GitHub Pages: https://youni202.github.io/AIplayground/
- Current site: https://ai-noriter-season2.youni.chatgpt.site/

## Content structure

- Season 1: 네 번의 공식 행사와 행사별 상세 갤러리
- Season 2: BUILD와 Snowflake 공식 행사
- Small Playground: 시즌제로 이어지는 소규모 실습 프로그램
- People: 모임장과 운영 조직

## Build

```bash
npm install
npm run build:github-pages
```

`docs/` contains the static GitHub Pages export. Pushing `main` deploys that folder through GitHub Actions.
